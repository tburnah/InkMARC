## Existing grants remain relevant

At the cloned base commit
`715d1ce7e2b0e9432cf2c1e29246c51a9d1eecc7`, the root license was
CC BY-NC 4.0. The root README explicitly offered noncommercial reuse and
also contained a conflicting Apache 2.0 statement. Deform contained an MIT
notice. Replacing the root notice does not erase this history or make
previously licensed, unchanged code exclusively proprietary.

CC BY-NC 4.0 §2(a)(1) describes the grant as irrevocable, and §6(c)
states that stopping distribution or offering separate terms does not
terminate it. See the [controlling CC legal text](https://creativecommons.org/licenses/by-nc/4.0/legalcode.en)
and [Creative Commons explanation](https://creativecommons.org/faq/#what-if-i-change-my-mind-about-using-a-cc-license).
The current reservation therefore excludes permissions already validly
granted for the covered material. It does not declare a retroactive change.

The former Apache statement is preserved as evidence of historical wording;
the scope of any valid prior grant is not resolved by deleting that sentence.
Deform's component notice now states all rights reserved for original
contributions. The complete historical MIT text remains verbatim beneath a
historical-grants heading in that file and in the history copy below; its
existing scope is not silently narrowed to a guessed dependency. The seven
other components now have explicit reserved-rights notices as well.

The following exact pre-update documents are retained:

- [Root license](history/root-LICENSE-before-archive-update.txt)
- [Root README](history/root-README-before-archive-update.md)
- [Deform MIT notice](history/Deform-MIT-at-clone.txt)

Historical files are evidence, not an offer of their blanket wording for

## Third-party scope

[Third-party notices](../../THIRD_PARTY_NOTICES.md) distinguish declared
packages, the existing native runtime archive, fonts, music and model files.
[Exact-version NuGet metadata](nuget-license-evidence.json) records 52
package/version pairs from eight project files. This is a declared dependency
inventory, not a restored transitive dependency graph or a full binary SBOM.

Software licenses do not alone establish model, dataset, music or artwork
redistribution rights. Existing repository assets and binaries require their
own provenance review. The separate Phase B licensing records apply to its
selected VM files and remain intact in the imported
[VM licensing documentation](../../research/docs/licensing.md),
[third-party notices](../../research/THIRD_PARTY_NOTICES.md) and
[model-rights map](../../research/provenance/model-licensing.json).
The repository-level prior-grant and third-party exceptions also apply to
imported material. A byte-preserving copy does not make previously licensed
source exclusively proprietary or establish model redistribution permission.

# Archive scope and remaining author decisions

This snapshot is organised for examination without rewriting the research.
The remaining decisions concern archive completeness and release selection.

- Confirm exact checkpoint/run associations for reported thesis experiments;
  component and architecture matches are already indexed.
- Select any additional preliminary/historical checkpoint families to retain.
  Unselected files remain untouched in the source workspace.
- Approve any dataset, split manifest, example, texture or participant-derived
  output before adding it to the public candidate.
- Supply complete application sources if Capture, Cue, Train, Probe, Prepare,
  Clean, Surface or the integrated phone application are to be included.
- Reserved-rights terms are now selected for original contributions; confirm any remaining upstream model/asset distribution rights separately.
- Choose final large-file distribution and GitHub publication steps later.

Historical absolute paths and missing external inputs affect execution away
from the VM. The archive records them rather than silently changing source
or regenerating inputs. Existing source and original documentation remain
available for inspecting historical assumptions.

The supplied thesis PDF, evaluation workbook, pipeline SVG, sample recordings,
texture images, raw data, logs and generated visualisations are not included.
Detailed local inventories and source-location records are kept in the
staging directory's sibling `review-only/`, outside this publication root.

This document concerns preparation of the code archive, not a reassessment
of the thesis reporting or experimental conclusions.
